# Цып-Цып — Three.js WebGL

Это доработка исходной версии **Three.js/WebGL**, а не новая Canvas-версия.

Исправлено:
- уменьшен размер Цыпы;
- переработана физика прыжка;
- добавлены короткое окно буфера прыжка и coyote-time;
- плавнее дуга прыжка и приземление;
- исправлен настоящий визуальный подкат;
- улучшена справедливость высоты прыжка относительно препятствий;
- свайпы привязаны к игровому Canvas.

Управление: свайп влево/вправо — полосы, вверх — прыжок, вниз — подкат.
Three.js подключается через CDN.
